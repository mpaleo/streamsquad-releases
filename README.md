# StreamSquad desktop downloads

StreamSquad is an Escape from Tarkov companion for solo raids and squads: maps, silent screen sharing, optional squad voice, and chat.

[Visit StreamSquad](https://streamsquad.app) · [Download for Windows](https://streamsquad.app/download/windows) · [All releases](https://github.com/mpaleo/streamsquad-releases/releases)

This public repository hosts desktop installers. Application development takes place in a separate repository.

## Windows

Download the x64 `.exe` installer from the latest release. The first desktop release is an unsigned preview; Windows may display an unknown-publisher warning. Installation and in-game behavior are being tested.

The desktop app shares the website's screens and account, with global shortcuts and a floating map/streams window. Use borderless/windowed mode for the overlay.

| Shortcut | Action |
| --- | --- |
| Ctrl + Alt + M | Switch between streams and map |
| Ctrl + Alt + V | Mute/unmute after joining squad voice |
| Ctrl + Alt + T | Open/close squad chat |

Capture starts only after selecting a screen or window. Voice starts only after joining. Updates currently require downloading a new installer.
